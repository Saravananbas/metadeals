# M2.5 — Authentication, Authorization and Admin Foundation

## Objective

Build a secure foundation for administrator access and a usable admin application shell, using the authentication/database libraries already present in the repository.

## Discovery first

Inspect:
- Existing authentication dependencies/configuration
- Prisma schema and database migrations
- Current routes and layouts
- Existing user model, if any
- Session strategy and environment variables
- Existing UI component conventions

Do not install a second authentication system if one is already configured. Do not replace working infrastructure.

## Requirements

1. Implement sign-in and sign-out using the selected existing auth configuration.
2. Protect all admin routes server-side.
3. Add role-based authorization, at minimum:
   - `ADMIN`
   - `EDITOR`
   - `VIEWER`
4. Enforce authorization in server actions/API handlers, not only by hiding UI.
5. Provide a clean admin layout/navigation matching MetaDeals4U design tokens.
6. Add admin overview placeholders backed by truthful empty states, not fabricated metrics.
7. Add user-friendly loading, validation and error states.
8. Use secure password/session practices appropriate to the chosen auth provider.
9. Add rate limiting or document the existing protection strategy for authentication endpoints.
10. Provide a safe initial-admin provisioning approach; never hardcode credentials.
11. Add audit events for sensitive administrative changes where practical.
12. Keep public deal browsing separate from admin authorization.

## Security

- No default production password.
- No credentials in source control.
- No role decisions based only on client-side state.
- Validate inputs server-side.
- Avoid exposing session secrets or sensitive user fields.
- Do not weaken security to make tests pass.

## Tests

Cover unauthenticated access, authorized admin access, role restrictions, sign-out/session behavior and protected mutations.

## Out of scope

Do not implement full deal CRUD here. Prepare the secure admin foundation and shell for M3.
