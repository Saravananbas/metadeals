## Migration dates (investigated)
The identifiers `20261122100000_forum_notifications` and `20261123100000_forum_announcements` (and `20261118` to `20261121`) are **dated in the future** relative to today (13 Nov 2026). This is intentional: the repository's own earlier forum migrations were already future-dated when they were committed on 13 Nov (`20261114100000_community_forum`, `20261115100000_forum_profile_avatar`, `20261116100000_direct_messages`), and `20261117100000_forum_post_views` is already applied on staging. Prisma applies migrations in name order and refuses a new migration that sorts before one already applied, so each new migration had to be named after the last applied one; one day per migration was used. They have no dependency on the calendar. They must **not** be renamed: staging's migration history already records `20261117100000`. Suggestion for later: after launch, new migrations could use real timestamps only once the real date passes `20261123`.
